WordPad Removed From Windows 11 — How to Open RTF Files Now

November 15, 2026 · 3 min read

If you updated Windows and your .rtf files suddenly stopped opening, nothing is broken on your side. Microsoft removed WordPad — the little word processor that came free with Windows and used RTF as its native format — from Windows 11 in the 24H2 update. Here is what happened and what to do instead.

What happened to WordPad

WordPad was removed from all editions of Windows starting with Windows 11 version 24H2 (and Windows Server 2025). Microsoft had deprecated it in 2023, and the 24H2 update is where it actually disappeared. The stated reason is simple housekeeping: WordPad had not received meaningful feature updates in years, and Microsoft chose to retire it rather than keep maintaining aging code.

Two things are worth knowing right away:

  • Your files are fine. Only the app is gone. Every .rtf file you have is unchanged and will open in any RTF-capable program exactly as before.
  • There is no supported way to get WordPad back. It is not in the Microsoft Store, and Microsoft does not offer an official reinstall.

Can you download WordPad again?

Only from unofficial websites — and that is exactly what you should not do. There are many "download WordPad for Windows 11" pages, and none of them can offer the real thing: they distribute old, repackaged files, which makes them a well-known malware vector. Nothing on those sites is signed or updated by Microsoft. If a page promises to bring WordPad back, close it and pick one of the replacements above instead.

What about Windows 10 and older PCs?

WordPad is still there on Windows 10 and earlier. If you have an older PC at home or in the office, its RTF files will keep opening as always. The removal applies to Windows 11 24H2 and Windows Server 2025 onward.

Frequently asked questions

Why was WordPad removed from Windows 11?

Microsoft removed WordPad in Windows 11 version 24H2 (the 2024 feature update) and in Windows Server 2025. WordPad had not received meaningful updates in years, and Microsoft decided to retire it rather than keep maintaining aging code.

Can I reinstall WordPad on Windows 11?

No. There is no supported way to reinstall WordPad on current Windows, and it is not in the Microsoft Store. Websites offering a WordPad download for Windows 11 are unofficial repackaged files and a common malware vector — do not install them.

What replaced WordPad for opening RTF files?

No single app replaced it. For RTF the closest free equivalent is LibreOffice Writer; Word for the web and Google Docs also open RTF in the browser. Notepad can show the raw text but not the formatting.

Are my old .rtf files lost after the WordPad removal?

No. The files themselves are unchanged and still valid — only the built-in app that opened them is gone. Any RTF-capable app (LibreOffice, Word, Google Docs) opens the exact same files as before.

Does Windows 10 still have WordPad?

Yes. WordPad is still present on Windows 10 and older; the removal applies to Windows 11 version 24H2 and Windows Server 2025 and later.

How do I download WordPad on Windows 11?

You should not. WordPad is not available from the Microsoft Store, and every site offering a WordPad download for Windows 11 distributes unofficial repackaged files — a common malware vector. Use LibreOffice Writer, Word Online, or an RTF-to-PDF converter instead.
