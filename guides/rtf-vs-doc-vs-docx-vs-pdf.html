RTF vs DOC vs DOCX vs PDF: What's the Difference?

November 7, 2026 · 3 min read

Short version: RTF is a universal exchange format for formatted text, DOC/DOCX are working formats you edit in Word, and PDF is a finished, frozen page for sharing. Write in DOCX, exchange via RTF when old software demands it, share as PDF.

RTF — the translator

Rich Text Format exists so that formatted documents survive the trip between different programs and platforms. It is plain text with formatting spelled out, which makes it universally readable and slightly heavier than DOC. Its specification has not changed since version 1.9.1 in 2008 — and that stability is the feature. You meet RTF today mostly as an output of old systems and as an input everything still accepts.

DOC and DOCX — the workshop

DOC is the classic binary Word format; DOCX replaced it in 2007 as an open XML-based standard. DOCX files are smaller, less corruption-prone, and store more (smart fields, modern table features). These are formats you work in, but what the reader sees still depends on their software, which is why a DOCX resume can arrive looking nothing like it did on your screen.

PDF — the finished product

PDF stores the page itself: every glyph, position, and image, fixed. That is why a contract in PDF looks identical on any device and why institutions ask for it. The trade-off is editability: PDF is the format you hand out, not the one you draft in.

So which one do I use?

  • Drafting or editing a document: DOCX, or RTF if the other side's software is old.
  • Sending something official: PDF, always.

Frequently asked questions

Is DOCX better than RTF?

For documents you keep working on, yes — DOCX stores richer formatting in smaller files and is the native format of modern Word. RTF's advantage is different: it is understood by virtually every word processor ever made, including old ones, which is why it still shows up as an exchange format.

Why does RTF still exist?

Because it does one job well: moving formatted text between different programs and decades of software. Old business systems, databases and documentation tools still export RTF, and every word processor still opens it, so the format refuses to die.

Can a PDF be edited like a Word document?

Not really. PDF is a fixed-layout format meant for finished documents; you can annotate it or fill forms, and dedicated tools can make limited edits, but rewriting content is done in the source document — then re-exported to PDF.

Which format should I use to send a resume or contract?

PDF. It freezes the layout so the document looks identical on the recipient's device, it cannot silently reflow, and every device opens it. Sending DOCX or RTF risks the formatting falling apart on their software.
